# Lección: el arrastre se hace desde la fuente

Después de un hueco (vacaciones, feriados), los bloqueos se arrastran leyendo el **último daily real**, no la memoria. La memoria pierde ~30% de los items; la fuente pierde 0.

Evidencia: arrastre post-vacaciones 18/18 sin pérdidas cuando lo hizo el agente desde [[Bloqueos]].
